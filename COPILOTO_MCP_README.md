# Copiloto MCP (somente leitura)

Contrato inicial para consultas de disponibilidade, reservas, chegadas/saídas e governança. Operações de escrita, cancelamento e alteração de reserva são proibidas. Em falha da API, o copiloto deve informar indisponibilidade e nunca inferir quarto livre. A implementação do endpoint MCP separado deve ocorrer após testes com dados fictícios e aceite da recepção.
